# Tutorias

1. Git pull
    trae la base de datos y hace merge al local del remoto
2. Git merge [Nombre de la rama] (opcional)
    fusiona la rama que especificas con la que estás
3. Git add .
    añade todos los archivos a ser trackeados.
4. Git commit -am [Mensaje entre commillas]
    hace una snapshot de tu codigo como está en ese momento.
5. Git push
    Envía los commit que tienes en local al remoto
